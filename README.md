# Java Environment Check

My first Java project, created to validate my development environment and begin building a professional Java backend development portfolio.

## Technologies
- Java 21
- Apache Maven
- IntelliJ IDEA
- Git & GitHub

## Features
- Prints a confirmation message to the console.
- Displays the current Java runtime version.
- Demonstrates a basic Java application entry point.

## How to Run
1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK 21 is configured.
4. Run the `Main` class.

## Learning Objectives
- Set up a Java development environment.
- Understand basic Java project structure.
- Build a project using Maven.
- Practice Git version control and GitHub.
